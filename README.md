# Customer Support Ticket Classification System

Predicts customer support ticket categories and priority levels using Natural Language Processing (NLP) and Machine Learning techniques.

# What it does
- Cleans and preprocesses ticket descriptions
- Removes unnecessary words using NLTK
- Converts text into numerical features using TF-IDF
- Uses Logistic Regression for classification
- Evaluates performance using accuracy scores and classification reports
- Predicts ticket categories and priority levels from user input

# Results
- Ticket category prediction
- Ticket priority prediction
- Accuracy evaluation using machine learning metrics

# Business Use
This system helps businesses automatically categorize support tickets, identify urgent issues, reduce response times, and improve customer satisfaction.
